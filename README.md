# Concepts Digital — Home

Home de concepto para Lola Casademunt (campaña Black Wild Friday), exportada desde Figma ([Concepts-digital › Home - Desktop](https://www.figma.com/design/dcIrJRloarFIPWyKGy8siz/Concepts-digital?node-id=59-154)) a HTML + CSS + JS sin dependencias.

## Estructura

```
index.html      Maquetación
styles.css      Estilos (tokens de color y tipografía en :root)
script.js       Interacciones: barra de anuncios, menú, bolsa, categorías, newsletter
assets/
  icons/        SVG (iconos y logotipos)
  img/          Fotos de categorías
  video/        Vídeo del hero
```

## Ver en local

Abre `index.html` en el navegador, o sirve la carpeta:

```
npx serve .
```

## Notas

- Diseño desktop a ancho fijo de 1440 px, igual que el frame de Figma.
- Tipografías desde Google Fonts: Manrope, Playfair Display SC y Mr Dafoe.
